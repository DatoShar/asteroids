# Asteroids

A complete Pygame Asteroids game.

## Run

Requires Python 3.13 and `uv`.

```bash
uv sync
uv run main.py
```

## Controls

- `A`: Rotate left
- `D`: Rotate right
- `W`: Move forward
- `S`: Move backward
- `Space`: Shoot

## Gameplay

Shoot asteroids to destroy them. Large asteroids split into two medium asteroids, and medium asteroids split into two small asteroids. Small asteroids disappear.
